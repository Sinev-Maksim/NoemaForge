Windows one-liners (CMD + PowerShell)
====================================

Replace placeholders:
  <BrainRoot>  = path to the repo folder (where manifest.yaml lives)
  <LabRoot>    = path to the lab folder (recommended sibling, e.g. ..\noemaforge-lab)
  <PythonExe>  = full path to python.exe (optional if Python is in PATH)

CMD (Command Prompt)
--------------------

Run Lab prep (recommended via run_lab.cmd):
  cd /d "<BrainRoot>" && tools\windows\run_lab.cmd "<LabRoot>" "<PythonExe>"

Run checker (deep):
  cd /d "<BrainRoot>" && powershell -NoProfile -ExecutionPolicy Bypass -File tools\windows\noemaforge_check.ps1 -Root "<BrainRoot>" -Deep

PowerShell
----------

Run Lab prep (recommended via run_lab.cmd):
  Set-Location "<BrainRoot>"; & ".\tools\windows\run_lab.cmd" "<LabRoot>" "<PythonExe>"

Run checker (deep):
  Set-Location "<BrainRoot>"; & powershell -NoProfile -ExecutionPolicy Bypass -File ".\tools\windows\noemaforge_check.ps1" -Root "<BrainRoot>" -Deep

Optional: pre-start simulation (cross-platform)
----------------------------------------------

This creates a temporary lab folder + minimal sample data and runs:
  scan_library, scan_vault, scan_tabs, scan_tg, generate_head_gateway_assets.

  Set-Location "<BrainRoot>"; & "<PythonExe>" .\tools\sim\simulate_prestart.py --brain-root . --out .\reports\sim
