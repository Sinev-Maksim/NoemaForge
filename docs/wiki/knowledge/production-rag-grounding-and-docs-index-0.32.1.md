# Production RAG grounding and docs index

Status: documentation compatibility anchor for the 0.32.1 GraphRAG experiment pack.

NoemaForge production RAG uses grounded documentation and knowledge graph references rather than free-form answers from raw chunks. Docs RAG, GraphRAG experiments and knowledge projections must preserve source references, graph refs, generated_at metadata, and a not-source-of-truth notice where human-readable pages are projections.

This page exists as a stable documentation reference for offline validation. It does not make wiki pages canonical and does not allow ungrounded publication.

Required concepts:

- grounded retrieval
- docs index
- graph-backed provenance
- projection is not source of truth
- review before publication
- freshness-bounded research packets
