# Mandatory Assistant/Package Self-Check

Before handing any new Night Watch bundle to the user, all applicable checks must be PASS:

## Contract / architecture
- [ ] every cross-component enum/status/capability interface has one machine-readable source of truth;
- [ ] call-site values and consumer/producer bindings pass contract-parity preflight;
- [ ] executable package dependency closure is declared and complete before worktree/provider/model activity;
- [ ] structural package/environment failure short-circuits all expensive agent work;
- [ ] exact base is explicit and checked at runtime;
- [ ] source-of-truth schemas/contracts are reused, not duplicated ad hoc;
- [ ] persona/capability/provider/independence are separate;
- [ ] local same-provider review is not labelled independent;
- [ ] review failure short-circuits reproducer/cost/budget/GCP;
- [ ] no remote/GCP side effects exceed current authorization.

## External process boundaries
- [ ] no large/model/user text is placed in argv;
- [ ] argv integrity smoke covers spaces/quotes/metacharacters;
- [ ] stdin/file protocol writes explicit UTF-8 bytes;
- [ ] non-ASCII transport canary exists;
- [ ] interactive auth is not piped/headless;
- [ ] process exit, protocol success, mutation success and review quality are distinct states;
- [ ] Windows PowerShell 5.1 runtime behavior is tested, not only parsed.

## Filesystem / portability
- [ ] native Path semantics are used for containment/security;
- [ ] externally serialized paths/artifact IDs are POSIX-normalized;
- [ ] runtime discovery searches beyond PATH before portable fallback;
- [ ] portable fallback is hash-pinned;
- [ ] host PATH/registry/global Git/PowerShell policy remain unchanged.

## Repair loop
- [ ] `stagnation_limit_per_task=4` by default;
- [ ] `traversal_depth_limit=0` means unlimited;
- [ ] global iteration limit is 0/unlimited by default;
- [ ] stable task identity ignores timestamps/temp paths/noisy fingerprints;
- [ ] product attempt is charged only after candidate materialization + post-fix gate;
- [ ] provider/transport failures are typed separately;
- [ ] control-plane failures cannot create product task keys or product-code edits;
- [ ] control-plane recovery has a separate bounded retry budget;
- [ ] unchanged patch SHA + same product task is treated as stagnation/no progress.

## Review / machine verdicts
- [ ] verdict parsing reads only the designated machine-output/last-message channel;
- [ ] stderr is diagnostic-only and excluded from verdict parsing;
- [ ] exactly one structured result is required;
- [ ] review result binds exact candidate SHA and immutable evidence SHA;
- [ ] malformed/contradictory/stale result is unavailable/fail-closed, never PASS;
- [ ] same-provider local co-check is optional/not independent;
- [ ] local co-check provider/protocol unavailability does not replace remote independent review;
- [ ] shell-independent exact-patch review evidence is available when local shell access is unavailable.

## Proposal application
- [ ] CRLF/LF proposal preimages are matched on canonical LF logical text;
- [ ] original target newline style is preserved on write-back;
- [ ] mixed-newline target fails closed;
- [ ] path allowlist, unique-preimage, size and immutable-test guards remain active.

## Tests / evidence
- [ ] existing tests are hash-locked/immutable;
- [ ] generated bytecode is excluded;
- [ ] `git diff --check` distinguishes errors from known benign EOL warnings;
- [ ] unexpected changed paths fail closed;
- [ ] terminal PASS/STOP/error creates READY signal + compact handoff archive;
- [ ] archive has manifest and SHA-256 and excludes disposable worktrees.

## UAT finding discipline
- [ ] root cause, not only symptom, is fixed;
- [ ] generalized regression/static guard added;
- [ ] prerequisite and package-fallback issue tracks updated;
- [ ] comment documents invariant + finding ID + removal condition.
