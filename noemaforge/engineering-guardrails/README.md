# NoemaForge Architecture Guardrails v1.0

Reusable architecture/policy package for NoemaForge and Night Watch.

Start with:
- `ASSISTANT_CONTEXT.md` — paste into another ChatGPT/agent chat;
- `ARCHITECTURE_PRINCIPLES.md` — human-readable source of truth;
- `policy/engineering-guardrails.v1.json` — machine-readable policy;
- `SELF_CHECK.md` — mandatory pre-delivery checklist;
- `ANTI_PATTERN_CATALOG.md` — known repeated rakes;
- `lint/guardrails_lint.py` — static package linter.

The package intentionally distinguishes recovered agreements from newly recommended generalized guards.
