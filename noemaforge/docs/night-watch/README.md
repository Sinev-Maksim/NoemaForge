# Night Watch Development Area

This directory is the repository-canonical, non-secret development context for Night Watch.

Read in this order:

1. [NIGHT_WATCH_DEVELOPMENT_RULES.md](NIGHT_WATCH_DEVELOPMENT_RULES.md)
2. [NIGHT_WATCH_STATUS.md](NIGHT_WATCH_STATUS.md)
3. [NIGHT_WATCH_CONTEXT.md](NIGHT_WATCH_CONTEXT.md)
4. [NIGHT_WATCH_RECOVERY.md](NIGHT_WATCH_RECOVERY.md)

The `night-watch` branch is a development/checkpoint branch. An incomplete checkpoint marked `unstable, saved for context` is durable context, not a release or merge approval.

Secret/internal directives are intentionally excluded from this directory and from ordinary handoff/evidence artifacts.
