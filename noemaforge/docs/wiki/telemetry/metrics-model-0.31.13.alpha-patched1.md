# NoemaForge telemetry and metrics model

> **Status: historical snapshot (0.31.13.alpha-patched1 era).** Kept as release-evidence history; it is not maintained. For the current state start at the [wiki hub](../WIKI.md).

Version: `0.32.1`

## Metric classes

- Hardware telemetry: temperature, battery, power, fan/thermal status, RAM, swap, disk and GPU state.
- Runtime telemetry: active model, active persona, backend id, CPU/GPU mode, PID, RAM/VRAM usage, latency and job status.
- Product metrics: before/after tests, benchmarks, coverage, memory footprint, error counts, scorecards and rollback evidence.

Creative media tasks must be marked as review-required unless a dedicated evaluator exists. The GUI must not claim objective creative improvement without evidence.
