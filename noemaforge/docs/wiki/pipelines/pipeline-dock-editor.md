# NoemaForge 0.31.13.alpha-patched1 — Pipeline Dock and Editor Plan

## Left click
Open a pipeline, explain it, request required inputs, then run or create a plan according to policy.

## Right click
Open visual diagram, show stats, show last runs, show artifacts, edit draft TODO, clone/new pipeline TODO.

## New pipeline
The `+ New Pipeline` control creates draft-only records. Activation requires schema validation plus Scary, Architecture and Admin approval.
