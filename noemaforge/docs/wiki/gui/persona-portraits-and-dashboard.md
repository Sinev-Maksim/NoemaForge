# NoemaForge 0.31.13.alpha-patched1 — persona portraits and Admin Chat

Persona portraits are now used by the chat-first Admin GUI. The active persona portrait changes when Admin hands work to Dev Team, Optimizer, Model Evolution or media teams.

The transcript must include a localized persona switch line, for example:

```text
-- смена персоны с Admin на Dev Team --
```

Raw runtime JSON is no longer the primary GUI answer. It is available under details/raw for debugging.
