# NoemaForge 0.32.1 — Tasks and Inactivity Policy

> **Status: historical snapshot (0.31.13.alpha era).** Kept as release-evidence history; it is not maintained. For the current state start at the [wiki hub](../WIKI.md).

## Purpose
Expose an inactivity timer and a task queue. Admin can add, edit and prioritize tasks. Future idle modes can take one task at a time by category.

## Dev backlog empty policy
If Dev Team has no tasks, create a seed self-optimization proposal against the latest seed version, plan-first, approval-gated, bounded by steps/time, and allowed to finish with `no_further_improvement_found`.
