# HOW2START — NoemaForge 0.32.1 (Italiano)

1. Verify the archive checksum.
2. Run `./setup.sh --mode vm --dry-run --selftest`.
3. Install on host with `sudo ./setup.sh --mode host --model-profile minimal --with-share /mnt/noemaforge-share`.
4. Keep display enabled by default during model selection.
5. Start GUI with `noemaforge gui console start --port 8765`.
