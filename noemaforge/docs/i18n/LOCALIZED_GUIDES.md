## Fragment 2: HOW2START

### NoemaForge 0.31.13.alpha HOW2START

#### Installation

```bash
cd ~/Downloads
sha256sum -c noemaforge_0.31.13.alpha_prelaunch.tar.gz.sha256
rm -rf noemaforge_0.31.13.alpha_prelaunch
tar -xzf noemaforge_0.31.13.alpha_prelaunch.tar.gz
cd noemaforge_0.31.13.alpha_prelaunch
./setup.sh --mode vm --dry-run --selftest
sudo ./setup.sh --mode host --model-profile minimal --with-share /mnt/noemaforge-share
hash -r
```

#### Prüfung

```bash
noemaforge version
noemaforge version-audit --json
noemaforge consistency-audit --json
sudo noemaforge trixie-preflight --json
NOEMAFORGE_PIPELINE_STATE=/var/lib/noemaforge/pipelines noemaforge pipeline validate
systemctl get-default
systemctl --failed --no-pager
```

#### GUI starten

```bash
noemaforge dashboard stop 2>/dev/null || true
noemaforge gui console start --port 8765
```

Open:

```text
http://127.0.0.1:8765/
```

#### First-start and model selection

```bash
sudo noemaforge first-start --normal --dry-run --show-candidates --per-model-timeout 240 --total-timeout 1200
noemaforge first-start summary --latest
```

Heavy real runs must be operator-approved and should be monitored from a terminal:

```bash
NOEMAFORGE_FIRST_START_TTY_STATUS_INTERVAL=10 sudo noemaforge first-start --full_composite 4 --show-candidates --show-compositions --per-model-timeout 240 --total-timeout 7200
```

Abort/recover:

```bash
sudo noemaforge first-start abort
sudo noemaforge emergency-recover
```

#### CPU/GPU policy

Telemetrie ist in hardware, runtime und product metrics getrennt. CPU/GPU policy ist staged und gilt beim nächsten Persona-/Modellwechsel oder Backend-Restart.

#### Hinweise

Einige Funktionen sind draft-only: drag-and-drop Pipeline-Editor, privileged GUI runner, GPU-generierte Avatare und live WebSocket progress.

NoemaForge 0.31.13.alpha — локальная alpha-сборка для контролируемой проверки Admin GUI shell, подбора моделей, Dev Team, метрик, задач, каталога пайплайнов, портретов персон и privacy-first roadmap пакетов.

#### Main additions

- Stateful Admin GUI shell with backend-owned conversation history.
- Persona portraits served through `/ui/...` with persistent deterministic fallback avatars.
- SR/SSR-ready message and artifact persistence.
- Epoch/model-selection panel with tested/failed/remaining progress.
- Task queue, inactivity timer, pipeline catalog, pipeline diagrams and stats.
- Hardware, runtime and product telemetry surfaces.
- Staged CPU/GPU device policy.
- Smart-home local-first backlog: value your privacy.

#### Safety model

Перед установкой останови runtime-сервисы NoemaForge, но не останавливай Debian display manager. Установку начинай с setup selftest, затем проверь version-audit, consistency-audit, trixie-preflight и pipeline validate.

Подбор моделей поддерживает fast, normal, full и full_composite. Тяжёлые или привилегированные действия выполняются plan-first и требуют approval. Смена эпохи создаёт audited apply request.

#### Known alpha limits

Часть функций остаётся draft-only: drag-and-drop редактор пайплайнов, автоматический privileged GUI runner, GPU-генерация аватаров и live WebSocket progress.

### NoemaForge 0.31.13.alpha user guide

#### What this build is

NoemaForge 0.31.13.alpha — локальная alpha-сборка для контролируемой проверки Admin GUI shell, подбора моделей, Dev Team, метрик, задач, каталога пайплайнов, портретов персон и privacy-first roadmap пакетов.

#### Admin GUI

Admin GUI хранит состояние на backend: история чата, артефакты, задачи, jobs, персона, эпоха и записи для SR/SSR восстанавливаются после обновления страницы.

#### Metrics

Метрики разделены на hardware, runtime и product. Политика CPU/GPU staged: применяется при следующей смене персоны/модели или перезапуске backend.

Smart-home и edge packs в alpha остаются roadmap-only. Принцип: value your privacy; не отправлять камеры, сенсоры и управление устройствами во внешний cloud по умолчанию.

## Fragment 34: HOW2START

### NoemaForge 0.31.13.alpha HOW2START

#### Встановлення

```bash
cd ~/Downloads
sha256sum -c noemaforge_0.31.13.alpha_prelaunch.tar.gz.sha256
rm -rf noemaforge_0.31.13.alpha_prelaunch
tar -xzf noemaforge_0.31.13.alpha_prelaunch.tar.gz
cd noemaforge_0.31.13.alpha_prelaunch
./setup.sh --mode vm --dry-run --selftest
sudo ./setup.sh --mode host --model-profile minimal --with-share /mnt/noemaforge-share
hash -r
```

#### Перевірка

```bash
noemaforge version
noemaforge version-audit --json
noemaforge consistency-audit --json
sudo noemaforge trixie-preflight --json
NOEMAFORGE_PIPELINE_STATE=/var/lib/noemaforge/pipelines noemaforge pipeline validate
systemctl get-default
systemctl --failed --no-pager
```

#### Запуск GUI

```bash
noemaforge dashboard stop 2>/dev/null || true
noemaforge gui console start --port 8765
```

Open:

```text
http://127.0.0.1:8765/
```

#### First-start and model selection

```bash
sudo noemaforge first-start --normal --dry-run --show-candidates --per-model-timeout 240 --total-timeout 1200
noemaforge first-start summary --latest
```

Heavy real runs must be operator-approved and should be monitored from a terminal:

```bash
NOEMAFORGE_FIRST_START_TTY_STATUS_INTERVAL=10 sudo noemaforge first-start --full_composite 4 --show-candidates --show-compositions --per-model-timeout 240 --total-timeout 7200
```

Abort/recover:

```bash
sudo noemaforge first-start abort
sudo noemaforge emergency-recover
```

#### CPU/GPU policy

Метрики розділено на hardware, runtime і product. Політика CPU/GPU staged і застосовується під час наступної зміни персони/моделі або restart backend.

#### Нотатки

Частина функцій лишається draft-only: drag-and-drop редактор пайплайнів, privileged GUI runner, GPU-аватари і live WebSocket progress.
