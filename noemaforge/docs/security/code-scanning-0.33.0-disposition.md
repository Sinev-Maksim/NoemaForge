## Release interpretation

This second pass fixes the safe, local code-owned findings and narrows workflow
token permissions where local YAML changes are sufficient. It does not claim
that all GitHub alerts are closed. It does not claim that all collected
code-scanning alerts are closed: governance settings, intentional write-token
jobs, pip hash-locking, fuzzing, OpenSSF/CII, and gateway binary provenance still
require operator or dedicated hardening follow-up before an unqualified release
claim. A production tag still needs operator acceptance of retained findings or
dedicated follow-up evidence.
