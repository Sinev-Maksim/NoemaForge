Этот запускатор делает один непрерывный цикл без ручного "ловления" шагов.

Что нового:
- если источник падает, он ставится на cooldown на 15 минут и запускатор сразу переходит к следующему источнику;
- для каждого источника ведутся свой fail-state, counter и timestamp;
- после прохода по всем источникам запускатор сам стартует новый pass;
- если до следующей попытки по источнику еще не прошло 15 минут, запускатор подождет до конца cooldown и продолжит сам;
- если у источника набирается MAX_FAILS_PER_SOURCE подряд, источник помечается hard-failed и запускатор заканчивает работу с кодом ошибки;
- OAPEN идет в fail-fast режиме: при первой ошибке шаг книг останавливается, источник уходит на cooldown, далее запускаются другие источники.

Файлы состояния:
- logs\_pipeline\pipeline_state.json
- logs\_pipeline\source_OAPEN.json и аналогичные для остальных источников
- logs\_pipeline\*.done

Сбросить состояние:
- удалить logs\_pipeline\pipeline_state.json
- удалить logs\_pipeline\source_*.json
- удалить logs\_pipeline\*.done

Запуск:
RUN_LIBRARY_PIPELINE.cmd
